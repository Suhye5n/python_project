# 카카오톡 (가짜) PWA

앱스토어에 올리지 않고, 아이폰 홈 화면에 아이콘으로 추가해서 쓰는 웹앱(PWA)입니다.
채팅 목록은 실제 카톡 스크린샷을 잘라 만든 이미지라서 프로필/이름/스킨이 실제와 동일합니다.

## 아이폰 홈 화면에 추가하는 법

1. 이 폴더를 HTTPS로 열람 가능하게 올려야 합니다 (예: GitHub Pages, Netlify, Vercel 등 정적 호스팅). 로컬에서만 테스트하려면 `python3 -m http.server 8000` 후 `http://<컴퓨터IP>:8000` 로 같은 와이파이의 아이폰에서 접속해도 화면 확인은 되지만, 서비스워커/뱃지는 HTTPS(or localhost)에서만 동작합니다.
2. 아이폰 Safari로 접속 → 공유 버튼 → "홈 화면에 추가".
3. 홈 화면에 노란 TALK 아이콘이 생깁니다.

## 화면 구성

- `index.html` / `style.css` / `app.js`: 채팅 목록 + 채팅방 2개 화면을 한 페이지에서 전환.
- `rows/`: 채팅 목록의 각 대화상대 한 줄 한 줄을 실제 스크린샷에서 잘라낸 이미지. 대부분은 통째로 이미지라서 코드로는 수정할 수 없습니다.
- `data.js`: **여기만 고치면 화면 내용이 바뀝니다.**
  - `ROWS` 배열이 목록 순서입니다. `editable: true`가 붙은 두 항목(굴비, 라고했을때시켜야짛는데/한되팔렘)만 `time`/`msg` 값을 코드로 바꿀 수 있고, 이름·프로필 사진은 이미지에 박혀있어 그대로입니다.
  - `tappable: true`가 붙은 항목(라고했을때시켜야짛는데/한되팔렘)만 눌러서 채팅방으로 들어갈 수 있고, 나머지는 눌러도 반응하지 않습니다.
  - `MESSAGES` 배열이 그 채팅방의 대화 내용입니다. 순서대로 나오고 스크롤됩니다.
  - `assets/friend-avatar.png`가 채팅방 안에서 쓰이는 그 친구 프로필 사진입니다 (실제 스크린샷에서 잘라낸 사진).

## 뱃지

`app.js`가 `navigator.setAppBadge()`를 호출합니다. iOS Safari는 16.4 이상에서, **홈 화면에 추가해서 실행한 경우에만** 앱 아이콘에 빨간 뱃지 숫자가 뜹니다. Safari 브라우저 탭으로 열어서 볼 때는 뱃지가 표시되지 않는 게 정상입니다.

## 이미지 재생성

- `gen_icons.py` (Pillow 필요: `pip install pillow`): `icons/` 안의 앱 아이콘(TALK 말풍선)을 다시 만듭니다.
- `crop_rows.py`: 원본 스크린샷에서 `rows/`, `assets/friend-avatar.png`를 다시 잘라냅니다. 스크립트 안 `IMG2`/`IMG3` 경로를 원본 스크린샷 파일로 바꿔서 실행하면 됩니다.
