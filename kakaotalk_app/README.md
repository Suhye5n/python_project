# 카카오톡 (가짜) PWA

앱스토어에 올리지 않고, 아이폰 홈 화면에 아이콘으로 추가해서 쓰는 웹앱(PWA)입니다.

## 아이폰 홈 화면에 추가하는 법

1. 이 폴더를 HTTPS로 열람 가능하게 올려야 합니다 (예: GitHub Pages, Netlify, Vercel 등 정적 호스팅). 로컬에서만 테스트하려면 `python3 -m http.server 8000` 후 `http://<컴퓨터IP>:8000` 로 같은 와이파이의 아이폰에서 접속해도 화면 확인은 되지만, 서비스워커/뱃지는 HTTPS(or localhost)에서만 동작합니다.
2. 아이폰 Safari로 접속 → 공유 버튼 → "홈 화면에 추가".
3. 홈 화면에 노란 말풍선 아이콘이 생깁니다.

## 화면 구성

- `index.html` / `style.css` / `app.js`: 채팅 목록 + 채팅방 2개 화면을 한 페이지에서 전환.
- `data.js`: 목록에 나오는 대화상대와 채팅 내용이 들어있는 파일. **채팅 내용을 바꾸고 싶으면 이 파일만 수정하면 됩니다.**
  - `CONTACTS` 배열의 `tappable: true` 가 붙은 항목(라고했을때시켜야짛는데/한되팔렘)만 눌러서 채팅방으로 들어갈 수 있고, 나머지는 눌러도 반응하지 않습니다.
  - `MESSAGES` 배열이 그 채팅방의 대화 내용입니다. 순서대로 나오고 스크롤됩니다.
  - `assets/friend-avatar.png` 가 그 친구 프로필 사진 자리입니다. 실제 사진으로 바꾸고 싶으면 같은 파일명으로 교체하세요.

## 뱃지

`app.js`의 `setBadge()`가 `navigator.setAppBadge()`를 호출합니다. iOS Safari는 16.4 이상에서, **홈 화면에 추가해서 실행한 경우에만** 앱 아이콘에 빨간 뱃지 숫자가 뜹니다. Safari 브라우저 탭으로 열어서 볼 때는 뱃지가 표시되지 않는 게 정상입니다.

## 아이콘 재생성

`gen_icons.py`, `gen_avatar.py` (Pillow 필요: `pip install pillow`)를 실행하면 `icons/`, `assets/` 안의 이미지를 다시 만들 수 있습니다.
